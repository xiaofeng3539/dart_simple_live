# 平台原生表情

用户确认范围：Windows/手机，聊天区与视频滚动弹幕均显示平台原图，不以 Unicode 近似图替代。

采用消息原生图片优先、平台/房间目录补全的方案；不用只有少量硬编码关键词的对照表。LiveMessage 保留原始文字用于屏蔽、复制与图片失败回退，另携带有序图文片段。B站解析 info 中的表情与 extra.emots；抖音解析 rtfContent 与独立表情消息；斗鱼、虎牙接入官方目录和消息标记。

聊天使用 WidgetSpan 与平台图片，滚动弹幕扩展现有 canvas_danmaku 本地副本，在排版时为图片预留空间、每帧绘制当前动图帧，沿用轨道/速度/透明度设置。保留上游许可证，不修改 pub-cache，不重写播放器。

图片加载去重、缓存、有界内存、释放监听；不等待图片下载才显示整条消息。未知或失效资源保留文字。远端 API 不提供图片、需登录或已删除的表情不宣称已支持。测试区分协议夹具验证与真实在线验证。

不改关注、同步、安装包签名与已有网络修复，不清用户数据。用户“继续”作为执行确认。
