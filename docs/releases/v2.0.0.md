# Simple Live 2.0

关注用户页面新增按游戏/直播分区分组展示，先按“全部 / 直播中 / 未开播”过滤，再显示分类标题和人数。

## 更新内容

- 分类标题采用现有分区页面样式，显示“游戏或分区名称 + 人数”。
- 同分类主播集中排列，保留原主播卡片、组内顺序、点击播放、标签管理和取消关注操作。
- 没有分类信息的主播归入“其他”。
- 保存现有详情请求返回的分类名称，兼容旧关注记录及关注文件导入导出。

## 使用说明

- 分类展示使用现有数据和本地缓存；部分平台或主播未提供分类名称时会显示在“其他”。
- 本版没有增加分类补查请求，没有修改直播解析、API、播放器或其他页面。
- 本次发布不附带安装包，安装包由维护者另行上传。
