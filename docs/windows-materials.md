# Windows 窗口材质

在「设置 → 外观设置 → 窗口材质与边框」选择：轻薄亚克力、标准亚克力、云母、云母 Alt、纯色。默认轻薄亚克力。选择与边框开关保存于现有设置存储，不修改关注数据。

- 轻薄与标准亚克力采用相同原生模糊效果，通过不同界面底色浓度区分。
- 云母需 Windows 11，云母 Alt 需支持对应 DWM 背景类型的版本。旧系统降级亚克力，不覆盖用户原选择。
- 关闭系统透明效果、启用高对比度或原生效果不可用时，界面使用不透明背景。
- Windows 11 支持系统边框开关，不改变标题栏按钮、窗口拖动、缩放和托盘功能。
- 材质仅用于窗口及界面背景。视频组件仍使用不透明黑底；手机主题不变。
- Windows 10 的原生亚克力在拖动窗口时可能有系统级性能限制，可选择纯色。

视觉概念参考 DeskBox：https://github.com/Tianyu199509/DeskBox 。本项目独立适配 Flutter，未复制其 WinUI/GPL 源码；原生效果使用 MIT 依赖 flutter_acrylic 1.1.4 和 Windows DWM 接口。
